# ADR-0003 — 계열사 확장을 위해 구조는 일반화하되, 계열사 관리 화면은 만들지 않는다

## 맥락

현재는 유진기업 1건만 시드되어 있지만, PRD는 동양/유진홈센터/자산운용을 이후 단계에서 추가할 계획임을 명시한다. 이번 범위에서 계열사 CRUD 화면까지 만들 필요는 없지만, 나중에 계열사를 추가할 때 코드를 다시 손대야 한다면 확장이 무의미해진다.

## 버린 대안

- **유진기업 하나만 지원하도록 하드코딩하는 것** — 계열사 선택 UI, API를 유진기업 전용으로 고정하는 방식.
- **계열사 추가/삭제 CRUD 화면을 이번 스펙에서 함께 구현하는 것** — 이번 범위(유진기업 1건)에는 과한 작업이다.

## 결과

계열사 선택은 `companies` 테이블을 그대로 읽어 구성하므로, 계열사가 늘어나도 코드 변경 없이 선택 목록에 자동 반영된다. 다만 계열사를 추가·삭제하는 화면은 없으므로, 신규 계열사 추가는 DB에 직접 데이터를 넣는 방식으로만 가능하다.
