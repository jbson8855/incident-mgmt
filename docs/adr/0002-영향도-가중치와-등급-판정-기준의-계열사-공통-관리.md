# ADR-0002 — 영향도 가중치와 등급 판정 기준은 계열사 공통으로 관리한다

## 맥락

`영향도-기준표-관리`와 `장애등급-계산` spec 문서는 대분류/중분류 가중치와 등급 판정 구간(1등급/2등급/3등급/등급외 경계값)을 "계열사별로" 조회·수정한다고 적었다. 그러나 유진기업 외 계열사(동양/유진홈센터/자산운용)를 검토하는 과정에서, 이 값들은 계열사마다 다르게 둘 이유가 없고 실제로 같은 값을 쓴다는 것을 확인했다. 계열사마다 달라지는 것은 "대상(업무서비스)" 시스템 목록뿐이다.

## 버린 대안

- **대분류/중분류 가중치와 등급 판정 구간을 계열사별로 각각 저장하는 것** — spec 문서의 원안. 계열사가 늘어날 때마다 값을 중복 입력·관리해야 하고, 계열사마다 값이 갈라질 위험이 있다.

## 결과

`impact_categories`, `impact_subcategories`, `grade_thresholds` 테이블에는 `company_id`가 없다. 모든 계열사가 동일한 가중치 체계(비즈니스영향도 50%/장애복잡도 20%/고객서비스영향도 30% 등)와 동일한 등급 경계값(0.8/0.7/0.5)을 공유한다. 계열사별로 다르게 두려면 스키마 변경(company_id 추가)이 필요하다.
