# ADR-0006 — 입력 항목을 "직접입력형"과 "3지선다 고정값형" 두 패턴으로 설계한다

## 맥락

서비스 장애 범위의 "일부"처럼 매번 다른 연속값(10~50%)이 필요한 항목과, 장애복잡도처럼 사전에 정해진 두 값(단순장애 0.2 / 복잡장애 0.8) 중 하나를 고르는 항목이 함께 존재한다.

## 버린 대안

- **모든 항목을 고정 선택지(체크박스/라디오)만으로 구현하는 것** — 비율을 직접 입력해야 하는 "일부 장애"의 10~50% 사이 값을 반영할 수 없게 된다.

## 결과

기준표 항목에 `min_value`/`max_value`가 설정되어 있으면 그 범위 안에서 값을 직접 입력받고(직접입력형), 없으면 "예/아니오/미확인" 3지선다로 기준표에 저장된 두 값 중 하나를 그대로 쓴다(고정값형). 두 가지 입력 패턴을 각각 검증해야 한다.
