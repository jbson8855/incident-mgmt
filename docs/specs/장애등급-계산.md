## Problem Statement

품질관리자는 장애가 발생하면 최대한 빠르게 장애등급을 판단해야 한다. 지금은 계열사별 장애등급 산정표(엑셀)를 열어서 항목을 체크하고 수식을 이해해야 하는데, 장애가 자주 발생하지 않다 보니 막상 그 순간에는 표가 낯설어 헷갈리고 판단이 늦어진다.

## Solution

품질관리자가 계열사를 고르고, 장애가 발생한 시스템과 나머지 항목(장애복잡도, 접속장애여부, 응답속도, 동일장애재발)을 화면에서 선택하면, 그 자리에서 점수를 자동으로 합산해 장애등급(1등급/2등급/3등급/등급외)을 즉시 보여주는 화면. 판단이 서지 않는 항목은 "미확인"으로 선택할 수 있고, 이 경우 등급이 더 높게(더 심각하게) 나오는 쪽으로 자동 계산해 신속한 초기 판단을 돕는다. 산정이 끝나면 그 결과는 자동으로 이력에 남는다.

## User Stories

1. As a 품질관리자, I want 계열사를 선택, so that 해당 계열사의 산정 기준으로 계산할 수 있다.
2. As a 품질관리자, I want 비즈니스영향도 항목에서 장애가 발생한 시스템을 그룹(ERP, 유관시스템, EURAS, 영업관리, 콘라이브, 기타 등)별로 찾아 여러 개 체크, so that 여러 시스템이 동시에 영향받은 경우도 빠짐없이 반영할 수 있다.
2-1. As a 품질관리자, I want 이번 장애가 전사 장애인지 일부 장애인지를 비즈니스영향도 영역 맨 앞에서 선택(전사=100% / 일부=10~50% 사이 직접입력)하는 것, so that 시스템은 같아도 장애 범위가 다르면 영향도 점수가 다르게 반영되게 할 수 있다.
3. As a 품질관리자, I want 장애복잡도를 단순장애 / 복잡장애 / 미확인 중 하나로 선택, so that 지금까지 확인된 정보만으로도 판단을 진행할 수 있다.
4. As a 품질관리자, I want 접속장애여부를 있음 / 없음 / 미확인 중 하나로 선택, so that 고객이 접속 자체를 못 하는 상황인지 반영할 수 있다.
5. As a 품질관리자, I want 응답속도 저하 여부를 있음 / 없음 / 미확인 중 하나로 선택, so that 서비스는 되지만 느려진 상황도 반영할 수 있다.
6. As a 품질관리자, I want 동일 장애 재발 여부를 있음 / 없음 / 미확인 중 하나로 선택, so that 예전에 같은 문제가 있었는지를 반영할 수 있다.
7. As a 품질관리자, I want 서비스 장애 범위 가중치·장애복잡도·접속장애여부·응답속도·동일장애재발 다섯 항목을 반드시 선택(일부 선택 시에는 비율까지 입력)해야만 계산이 진행되는 것, so that 빠뜨린 항목 없이 정확하게 산정할 수 있다.
8. As a 품질관리자, I want 판단이 애매한 항목은 "미확인"으로 선택할 수 있는 것, so that 확인 전에도 일단 신속하게 등급을 매길 수 있다.
9. As a 품질관리자, I want "미확인"을 선택한 항목은 자동으로 등급이 더 높게 나오는 값으로 계산되는 것, so that 정보가 부족한 상황에서도 안전한 쪽(더 심각한 쪽)으로 우선 판단할 수 있다.
10. As a 품질관리자, I want 담당자 팀장과 상의해서 값을 확정한 뒤 미확인 대신 정확한 값으로 다시 선택, so that 협의된 판단을 반영해 계산할 수 있다.
11. As a 품질관리자, I want 영향받은 시스템을 최소 1개는 선택해야만 계산이 진행되는 것, so that 어떤 시스템도 특정하지 않은 채 등급이 매겨지는 것을 막을 수 있다.
12. As a 품질관리자, I want 선택을 마치고 계산 버튼을 누르면 곧바로 총점과 등급(1등급/2등급/3등급/등급외)을 보는 것, so that 오래 기다리지 않고 바로 등급을 확인할 수 있다.
13. As a 품질관리자, I want 등급이 색으로 구분되어 보이는 것(예: 1등급은 빨강 계열), so that 심각도를 한눈에 알아볼 수 있다.
14. As a 품질관리자, I want 결과 화면에서 비즈니스영향도/장애복잡도/고객서비스영향도 각각의 점수도 따로 보는 것, so that 어떤 항목 때문에 이 등급이 나왔는지 이해할 수 있다.
15. As a 품질관리자, I want 계산이 끝나면 그 결과가 자동으로 이력에 남는 것, so that 나중에 다시 찾아보거나 장애보고서 작성 시 참고할 수 있다.
16. As a 품질관리자, I want 계산 결과를 확인한 뒤 곧바로 새 장애를 입력할 수 있게 화면이 초기화되는 것, so that 여러 건이 연달아 발생해도 빠르게 이어서 처리할 수 있다.
17. As a 품질관리자, I want 계산 전에 선택한 항목을 자유롭게 바꿀 수 있는 것, so that 잘못 선택한 것을 계산 전에 바로 고칠 수 있다.

## Implementation Decisions

- 이 화면은 "영향도-기준표-관리" 기능이 관리하는 계열사별 대분류/중분류/항목 데이터를 그대로 읽어서 선택지를 구성한다. 값이 하드코딩되지 않으므로, 기준표에서 값을 바꾸면 다음 계산부터 바로 반영된다.
- 계열사 선택: 현재는 유진기업만 시드되어 있어 사실상 하나만 고를 수 있지만, 선택 UI 자체는 계열사가 늘어나도 그대로 동작하도록 만든다.
- 입력 항목은 두 가지 방식으로 나뉜다.
  - **서비스 장애 범위 가중치(단일 선택, 장애 건 전체에 공통 적용, 비즈니스영향도 화면 맨 앞에 위치)**: "전사 / 일부" 중 하나를 고른다. "전사"는 기준표에 고정된 값(100%)을 그대로 쓴다. "일부"는 기준표에 설정된 허용 범위(기본 10~50%) 안에서 값을 매번 직접 입력해야 하며, "미확인" 개념은 적용하지 않는다(반드시 선택 + 일부면 입력까지 완료해야 계산 진행). 이 배율은 비즈니스영향도 소계에만 곱해지며 장애복잡도·고객서비스영향도에는 영향을 주지 않는다.
  - **비즈니스영향도(다중 선택)**: 그룹별로 정리된 시스템 목록에서 영향받은 시스템을 최소 1개 이상 체크해야 한다(0개면 계산이 진행되지 않는다). "미확인" 개념은 적용하지 않는다 — 장애 통지 시점에 이미 어떤 시스템인지는 특정되어 있다고 보기 때문이다. 점수는 선택된 시스템들의 값(반영률)을 모두 더한 값에 비즈니스영향도 대분류 가중치와 서비스 장애 범위 배율을 곱해 구한다. (예: 콘라이브(0.8)만 선택 + 일부 30% → 0.5 × 0.8 × 0.3)
  - **장애복잡도 / 접속장애여부 / 응답속도 / 동일장애재발(각각 단일 선택)**: "예 / 아니오 / 미확인" 3지선다로 제공한다. "예/아니오"는 기준표에 저장된 두 값(예: 단순장애 0.2 / 복잡장애 0.8) 중 하나를 그대로 쓴다. "미확인"을 선택하면 그 항목에 속한 두 값 중 더 큰 값(등급이 더 높게 나오는 쪽)을 자동으로 적용한다. 이 네 항목은 반드시 선택해야 계산이 진행된다(빈 채로 둘 수 없음).
- 총점 계산: `비즈니스영향도 대분류가중치 × (선택된 시스템 값의 합) × 서비스 장애 범위 배율(전사=1 / 일부=입력값)` + `장애복잡도 대분류가중치 × 선택(또는 미확인 처리)된 값` + `고객서비스영향도 대분류가중치 × (접속장애여부·응답속도·동일장애재발 각각의 중분류가중치 × 선택/미확인 값의 합)`.
- 등급 판정 기준: 총점이 0.8 초과이면 1등급, 0.7 초과 0.8 이하이면 2등급, 0.5 초과 0.7 이하이면 3등급, 그 외(0.5 이하)는 등급외로 판정한다. 비즈니스영향도에서 시스템을 여러 개 선택해 총점이 1.0을 넘는 경우에도 1등급으로 처리한다(상한 없음). 이 구간값은 하드코딩이 아니라 계열사별로 "영향도 기준표 관리" 화면에서 조회·수정하는 데이터다.
- 계산은 서버(API route)에서 수행한다: 화면에서 선택값을 서버로 보내면, 서버가 기준표 값(등급 판정 기준 포함)을 조회해 점수를 계산하고 등급을 판정한 뒤, 그 결과를 "장애-이력"에 한 건으로 저장하고 화면에 결과를 돌려준다. 미리보기만 하고 저장은 안 하는 별도 동작은 두지 않는다 — 계산 = 최초 산정 기록으로 취급한다(도메인 스토리의 "등급이 산정되면 업무가 끝난다"는 흐름과 일치).
- 안정화 기간 동안에는 계산하기 전에도 지금까지 선택한 값만으로 비즈니스영향도/장애복잡도/고객서비스영향도 소계와 합계를 화면에 실시간으로 미리 보여준다(선택 전 항목은 "-"로 표시). 계산 방식이 눈에 보이도록 돕기 위한 것으로, 이후 별도 요청이 있으면 제거한다.
- 결과 화면에는 최종 등급(색상 배지), 총점, 대분류별 소계(비즈니스영향도/장애복잡도/고객서비스영향도), 선택했던 시스템·항목 요약, 산정 시각을 표시한다.

## Out of Scope

- 산정된 등급을 조직원에게 전파하는 것(SMS/메신저 발송 등) — 다음 프로젝트에서 다룬다.
- 장애보고서 작성 시점에 등급을 다시 계산하는 재산정 기능 — 이번 화면은 최초 1회성 신속 산정만 다룬다.
- 계열사를 동시에 여러 개 계산하거나 계열사 간 비교.
- 계산 결과를 수정하는 기능 — 한 번 산정된 결과는 이력에 그대로 남고, 필요하면 새로 계산해 새 건으로 남긴다.

## Further Notes

- 이 기능은 "영향도-기준표-관리"에서 만든 기준 데이터가 있어야 동작하므로, 그 기능을 먼저 구현해야 한다.
- 계산 결과의 저장 형식(어떤 필드를 남기는지)은 "장애-이력" 스펙에서 정의한다.
