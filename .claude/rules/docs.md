# 문서 규칙

- `docs/specs/`는 **구현용 임시 문서**다. 구현이 끝나면 `spec-retire`로 제거한다.
- `docs/PRD.md`도 임시 문서다. 모든 spec이 정리된 뒤 제거한다.
- 현행 명세는 `tests/`다. 동작을 알고 싶으면 테스트를 읽는다.
- 결정 근거는 `docs/adr/`다.

## `docs/adr/` 불변 규칙

- **추가만 한다. 기존 ADR을 수정하지 않는다.**
- 결정이 뒤집히면 새 ADR을 만들고, 옛 문서에 `superseded by: NNNN` 한 줄만 덧붙인다.
- 동작 상세·코드·수치 규칙 본문을 쓰지 않는다. 테스트 파일 참조로만 가리킨다.
- `0001-구현범위.md`는 커버리지 맵이다. 범위가 늘면 행을 추가한다(번복이 아니므로 허용).
